# 💬 Chat SQLite & Interface Web HTML/CSS

Pour lancer l'application :
```bash
python run.py
```
Puis ouvrez votre navigateur sur : **http://127.0.0.1:8000**

Pour lancer la suite de tests :
```bash
python -m pytest chat_sqlite_app/tests -v
```
